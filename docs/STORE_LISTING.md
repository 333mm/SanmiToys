### 3. Description
> **Character Limit**: Up to 10,000 characters

```text
SanmiToys is a modular desktop utility suite designed for Windows 10 and Windows 11. It provides five independent tools to streamline daily window management, workspace focus, text recognition, audio adjustments, and device monitoring.

Each module can be enabled or disabled independently from the unified dashboard, allowing you to run only the tools you need.

■ Included Modules

1. FluidDrag (Window Dragging)
• Move application windows by clicking and dragging empty background areas, without needing to target the title bar.
• Configurable activation key (None/Always Active, Alt, Win) and drag initiation threshold (in pixels).
• Automatic suppression for full-screen games, video playback, and maximized windows.
• Flexible whitelist/blacklist filtering to exclude or include specific processes and window titles.

2. FocusDimmer (Background Dimming)
• Darkens inactive background windows and displays, highlighting only your active foreground window.
• Adjustable dimming opacity (0%–100%) and customizable overlay tint color with hex palette picker.
• Multi-monitor support with synchronized dimming across all connected displays.
• Optional idle dimming to darken screens when no keyboard or mouse activity is detected.
• Exclude specific background applications from dimming.

3. SnapTrans (Snipping OCR & Translation)
• Snip any rectangular area of your screen with a customizable hotkey (default: Alt + Q) to extract text using OCR.
• Translate captured text into your preferred target language. Supports free web translation, or connect your own API keys for DeepL, Google Gemini, or OpenAI GPT.
• Listen to extracted text with Text-to-Speech (TTS) voice playback.
• Optional popup toolbar upon selecting text on screen and automatic clipboard copying.

4. SwiftVolume (Audio & Microphone Utility)
• Adjust master output volume by scrolling the mouse wheel over the taskbar or notification area.
• Clean on-screen HUD displaying the current volume percentage during adjustments.
• Open an independent per-application volume mixer from the notification area to balance individual apps.
• Optional microphone tray icon with middle-click mute toggle and audio chime confirmation.
• Low-latency microphone monitoring with dedicated output routing, volume level, and noise gate.

5. OmniGlance (Status Island & Hardware Monitor)
• A compact desktop status capsule showing hardware metrics and wireless peripheral battery levels.
• Monitors battery percentages for compatible Bluetooth LE devices, Razer wireless peripherals, and system batteries.
• Real-time CPU, GPU, RAM load, and power consumption readouts.
• Choose between horizontal bar or vertical sidebar layouts, with configurable screen placement and scale.
• Click-through mode and auto-expand on mouse hover options.

■ Privacy & Architecture
• Local-First: All window operations, volume adjustments, and hardware readings are processed entirely on your local PC.
• No Account Required: No registration, tracking, or telemetry data collection.
• External Services: SnapTrans connects to translation endpoints only when you perform a translation request; third-party AI engines require your own API key.
• Language Support: English, Japanese, Simplified Chinese, Traditional Chinese, Korean, German, French, and Spanish.
```

### 3. 詳細な説明
> **最大文字数**: 10,000文字

```text
SanmiToysは、Windows 10 および Windows 11 向けに設計されたモジュール型のデスクトップユーティリティです。日々のウィンドウ操作、作業への集中、画面上の文字認識、オーディオ調整、周辺機器の確認をスムーズにする5つのツールを統合しています。

すべての機能はダッシュボードから個別にオン・オフを切り替えることができ、自分に必要なツールだけを選択して常駐させることが可能です。

■ 搭載モジュール

1. FluidDrag（ウィンドウ移動）
・タイトルバーを狙わなくても、ウィンドウ内の余白や背景部分をクリック＆ドラッグするだけでウィンドウを移動できます。
・有効化キー（常に有効、Alt、Win）やドラッグ開始までの移動閾値（ピクセル単位）を調整できます。
・全画面表示のゲームや動画再生中、最大化されたウィンドウでは自動的にドラッグが無効化されます。
・ホワイトリスト／ブラックリスト方式により、特定のアプリやウィンドウタイトルを柔軟に除外・登録できます。

2. FocusDimmer（背景画面の減光）
・作業中のアクティブウィンドウ以外の背景画面やデスクトップを暗く減光し、視覚的なノイズを低減します。
・減光の濃度（0%〜100%）やオーバーレイの色をカラーピッカーから自由に指定できます。
・マルチモニター環境に対応し、すべての接続ディスプレイで設定を同期できます。
・キーボードやマウス操作が一定時間ない場合に画面を暗くする無操作減光機能や、特定のアプリを除外する設定も可能です。

3. SnapTrans（範囲選択OCR・翻訳）
・ショートカットキー（初期値: Alt + Q）で画面の任意の矩形範囲を指定し、OCRで瞬時に文字を抽出します。
・抽出したテキストを指定の言語へ翻訳できます。無料のWeb翻訳のほか、ご自身のAPIキー（DeepL、Google Gemini、OpenAI GPT）を登録して利用可能です。
・抽出・翻訳したテキストの音声読み上げ（Text-to-Speech）に対応しています。
・画面上でテキストを選択した際に小さな操作ツールバーを表示する機能や、クリップボードへの自動コピーも備えています。

4. SwiftVolume（音量調整・マイクユーティリティ）
・タスクバーや通知領域のアイコン上でマウスホイールを回転させるだけで、PCの主音量をスムーズに調整できます。
・調整時には現在の音量パーセンテージを示すクリーンなHUDが画面上に表示されます。
・通知領域からアプリごとの個別音量スライダーを備えたミキサーウィンドウを開くことができます。
・マイクのトレイアイコンの表示、ホイールクリックでの即時ミュート、消音切り替え時の通知チャイムに対応しています。
・低遅延のマイク音声モニタリング（サイドトーン）機能を搭載し、音量調整やノイズゲートの設定が可能です。

5. OmniGlance（ステータスアイランド・機器監視）
・PCの負荷状況やワイヤレス周辺機器のバッテリー残量を常時確認できる小型のステータスカプセルを表示します。
・対応するBluetooth LE機器、Razerワイヤレス機器、ノートPC内蔵バッテリーの残量状態を可視化します。
・CPU負荷・温度、GPU負荷・温度、メモリ使用率、マシン消費電力のリアルタイム表示に対応しています。
・横型カプセルバーと縦型サイドバーのレイアウト選択、画面上の配置場所、表示倍率のカスタマイズが可能です。
・マウスクリックを透過するクリックスルーモードや、ホバー時の詳細自動展開に対応しています。

■ プライバシーと安心設計
・完全ローカル動作: ウィンドウ操作、音量制御、ハードウェア情報の取得はすべてお使いのPC内部で完結します。
・アカウント登録不要: ユーザー登録や行動ログの外部送信（テレメトリ）は一切行いません。
・外部通信の透明性: SnapTransで翻訳を実行した際のみ対象の翻訳サーバーへ通信を行います（AIモデル利用時はご自身のAPIキーを使用します）。
・多言語対応: 日本語、英語、簡体字中国語、繁体字中国語、韓国語、ドイツ語、フランス語、スペイン語に対応しています。
```
